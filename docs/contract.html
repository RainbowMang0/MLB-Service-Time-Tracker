What this page does not compute, and why

There is no modelled outcome for declining an offer, no projected arbitration salary, and no comparable-player set. All three need league-wide salary data, and this project has none.

The service-time database has never held salaries. Published arbitration projections are someone else's work, and republishing them is the same line this project already drew over Baseball Reference's figures and over MLB's photographs. No free, permitted, machine-readable salary source has been found.

A breakeven figure assembled from invented salaries would be the most confident-looking and least defensible number on this site, so the branch is absent rather than approximated. What is here instead rests on facts you supply or on figures the database already holds.
